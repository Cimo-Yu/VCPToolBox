[VCP百科全书] 插件说明——DailyHot（原子切片）

一、插件身份
- name: DailyHot
- displayName: 每日热榜
- pluginType: static
- command: 无（自动触发）

二、核心能力
- 在后台周期性地获取所有主流平台的今日热榜信息，并通过占位符 {{VCPDailyHot}} 提供。
- 以自动注入/后台服务方式提供能力，不要求直接命令调用。

三、占位符与注入点
- systemPromptPlaceholders: {{VCPDailyHot}}

四、配置重点
- 优先核对插件目录内的 plugin-manifest.json(.block) 与 config.env.example 必填项。
- 外部API类插件重点检查：密钥、端点、超时、代理与速率限制。
- 关键机制参数（源码事实）:
  * manifest 无 configSchema，插件目录无 config.env.example，源码不读取任何 API 密钥。
  * 数据源为 `dist/routes/*.js` 内置路由模块（bilibili、weibo、36kr 等约60+源），启动时自动发现并并发抓取。
  * 结果写入缓存 `dailyhot_cache.md`，抓取失败时降级读取缓存，并输出 vcp_dynamic_fold 折叠结构。
  * 刷新周期：manifest `refreshIntervalCron = 0 */4 * * *`（每4小时）。

五、排障建议
- 插件无响应：先检查 manifest 启用状态、入口脚本、运行时依赖。
- 结果异常：核对命令名与参数字段，再查看插件目录缓存/日志文件。

六、调用示例
触发示例：在系统提示词中引用该插件占位符，等待周期刷新后自动注入。
