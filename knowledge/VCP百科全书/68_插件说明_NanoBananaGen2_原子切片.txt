[VCP百科全书] 插件说明——NanoBananaGen2（原子切片）

一、插件身份
- name: NanoBananaGen2
- displayName: NanoBanana 图像生成 (自定义渠道)
- pluginType: synchronous
- command: generate, edit, compose
- 调用时使用工具名 NanoBananaGen2

二、核心能力
- 通过 OpenAI Chat Completions 兼容接口调用 Gemini/NanoBanana 图像生成模型（默认模型 gemini-3-pro-image）进行高级的图像生成和编辑。支持自定义 API 地址、多渠道绑定轮询（URL+KEY+多模型）、单渠道多模型随机、1K/2K/4K 尺寸选择与代理。
- 提供可调用命令：generate、edit、compose。

三、占位符与注入点
- systemPromptPlaceholders: 无

四、配置重点
- 优先核对插件目录内的 plugin-manifest.json(.block) 与 config.env.example 必填项。
- 外部API类插件重点检查：密钥、端点、超时、代理与速率限制。

五、排障建议
- 插件无响应：先检查 manifest 启用状态、入口脚本、运行时依赖。
- 结果异常：核对命令名与参数字段，再查看插件目录缓存/日志文件。

六、调用示例

1. generate - 生成图像
<<<[TOOL_REQUEST]>>>
tool_name:「始」NanoBananaGen2「末」,
command:「始」generate「末」,
prompt:「始」描述你想要生成的图像「末」
<<<[END_TOOL_REQUEST]>>>

2. edit - 编辑图像
<<<[TOOL_REQUEST]>>>
tool_name:「始」NanoBananaGen2「末」,
command:「始」edit「末」,
image_url:「始」https://example.com/photo.jpg「末」,
prompt:「始」编辑指令「末」
<<<[END_TOOL_REQUEST]>>>

3. compose - 合成图像
<<<[TOOL_REQUEST]>>>
tool_name:「始」NanoBananaGen2「末」,
command:「始」compose「末」,
prompt:「始」Use background from first image and character from second image「末」,
image_url_1:「始」https://example.com/background.jpg「末」,
image_url_2:「始」https://example.com/character.png「末」
<<<[END_TOOL_REQUEST]>>>
