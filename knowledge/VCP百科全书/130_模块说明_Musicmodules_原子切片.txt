[VCP百科全书] Musicmodules - 音乐播放器模块

一、模块基本信息
1. 模块名称：Musicmodules / 音乐播放器模块
2. 模块类型：前端UI模块
3. 版本号：1.0.0
4. 所属项目：VCPChat
5. 功能一句话总结：提供高保真音乐播放器，支持WASAPI、均衡器、歌词、可视化等功能

二、功能定位
Musicmodules是VCPChat的音乐播放器模块，提供专业级音乐播放体验。支持多种音频格式、WASAPI独占模式、10段均衡器、歌词显示、音乐可视化、播放列表管理、文件夹扫描等功能。

三、核心功能
1. 播放控制：
   - 播放/暂停
   - 上一曲/下一曲
   - 进度条拖拽
   - 播放模式切换（重复、单曲循环、随机）

2. 音频处理：
   - WASAPI独占模式
   - 10段均衡器
   - 均衡器预设
   - 重放增益
   - 上采样
   - 抖动处理

3. 播放列表：
   - 创建/编辑播放列表
   - 文件夹扫描
   - 搜索功能
   - 拖拽排序

4. 显示功能：
   - 专辑封面显示
   - 音乐可视化
   - 歌词显示（LRC格式）
   - 比特率显示

5. 设备管理：
   - 设备选择
   - WASAPI设备列表
   - 设备切换

6. 高级功能：
   - 歌词同步
   - 音乐分享
   - WebNowPlaying适配器
   - 主题切换

四、主要文件结构
- music.js：入口与装配（约50KB，setupPlayer/Output/Effects/UI等模块组装）
- music.html：UI布局
- music.css：样式定义
- socket.io.min.js：WebSocket库
- music-player.js：播放控制（loadTrack/playTrack/pauseTrack/prevTrack/nextTrack）
- music-output.js：设备、WASAPI独占、上采样、重采样控制
- music-effects.js：均衡器、响度模式、抖动优化
- music-lyrics.js：LRC歌词解析与同步
- music-visualizer.js：频谱与歌词可视化
- music-ui.js：界面与WebNowPlaying适配器
- music-sidebar.js：侧边栏与歌单管理
- music-webdav.js：WebDAV音频扫描
- music-song-presets.js：单曲参数预设
- music-utils.js：工具函数

五、关键API接口
1. 播放控制（music-player.js，app对象方法）：
   - app.loadTrack(index, andPlay)：加载曲目
   - app.playTrack() / app.pauseTrack()：播放、暂停
   - app.nextTrack() / app.prevTrack()：下一曲、上一曲

2. 播放列表（music-sidebar.js/music.js）：
   - app.api.addMusicFolder()：添加文件夹
   - app.showPlaylistDialog(callback)：创建播放列表
   - app.addSelectedTracksToPlaylist(playlistId)：添加到播放列表
   - app.api.saveMusicPlaylist(playlist)：持久化播放列表

3. 音频处理（music-output.js/music-effects.js）：
   - app.api.getMusicDevices()：获取输出设备列表
   - app.api.configureMusicOutput({device_id, exclusive})：设备选择与WASAPI独占开关
   - app.eqBands（32/64/125/250/500/1k/2k/4k/8k/16k十段）：均衡器调节
   - app.api.configureMusicUpsampling({target_samplerate})：上采样
   - app.api.configureMusicResampling({quality, use_cache, preemptive_resample})：重采样
   - app.api.configureMusicOptimizations({dither_enabled})：抖动处理

4. 显示：
   - app.parseLrc(lrcContent)：解析LRC歌词（music-lyrics.js）
   - app.visualizerColor = {r, g, b}：可视化颜色（music-visualizer.js）

六、使用场景
1. 音乐欣赏：高保真音乐播放
2. 播放列表管理：组织和管理音乐库
3. 音乐制作：使用均衡器调整音质
4. 歌词同步：显示实时歌词

七、与其他模块的关系
- 依赖 Electron API：与主进程通信
- 依赖 Socket.io：实时通信

八、注意事项
1. WASAPI仅在Windows上可用
2. 支持LRC格式歌词
3. 均衡器有多个预设
4. 可视化效果实时更新
