[VCP百科全书] 插件说明——DeepWikiVCP（原子切片）

一、插件身份
- name: DeepWikiVCP
- displayName: DeepWiki仓库文档检索
- pluginType: synchronous
- command: wiki_structure / wiki_content / wiki_ask

二、核心能力
- 一个同步插件，通过 DeepWiki 官方 MCP API 获取任意 GitHub 公开仓库的 AI 生成文档（目录结构、完整内容、AI 智能问答、Deep Research 深度研究、多仓库联合查询）。
- 提供可调用命令：wiki_structure（文档目录）、wiki_content（完整文档，超长自动截断）、wiki_ask（AI问答，支持 deep_research 与最多10仓库联合查询）。

三、占位符与注入点
- systemPromptPlaceholders: 无

四、配置重点
- 优先核对插件目录内的 plugin-manifest.json(.block) 与 config.env.example 必填项。
- 外部API类插件重点检查：密钥、端点、超时、代理与速率限制。

五、排障建议
- 插件无响应：先检查 manifest 启用状态、入口脚本、运行时依赖。
- 结果异常：核对命令名与参数字段，再查看插件目录缓存/日志文件。

六、调用示例
<<<[TOOL_REQUEST]>>>
tool_name:「始」DeepWikiVCP「末」,
command:「始」wiki_structure「末」,
url:「始」vuejs/vue「末」
