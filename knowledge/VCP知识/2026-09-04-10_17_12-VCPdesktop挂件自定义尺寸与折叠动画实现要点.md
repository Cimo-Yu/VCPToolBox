核心概念：VCPdesktop 挂件若要实现自定义尺寸变化（折叠/展开、手风琴、缩放态），不能依赖 widgetManager 的自动尺寸机制，必须由挂件脚本直接驱动外框元素，并显式关闭自动测量。

关键原理与三个阻碍点：

1. MutationObserver 的监听范围
setupContentObserver 的 observer.observe(contentContainer, { childList: true, subtree: true, characterData: true })。未包含 attributes，因此任何属性变更（class 切换、data-* 写入、style 修改）都不会唤醒观察器。企图通过改属性触发重测的做法无效。回调内另有 150ms 防抖，且仅在检测到 childList 增删或 characterData 变化时才调 autoResizeWidget。

2. autoResizeWidget 的测量依据
函数首行 if (widgetData.fixedSize) return。测量方式为临时将 contentContainer 设为 display:inline-block; width:auto，读取 scrollWidth/scrollHeight，再加 CONSTANTS.AUTO_RESIZE_PAD_W(8)/PAD_H(14)，并受 AUTO_RESIZE_MIN_W(140)/MIN_H(60) 与 AUTO_RESIZE_MAX_RATIO(0.85) 约束。因 opacity:0 与 visibility:hidden 均保留布局盒，用它们隐藏内容不会让测量值下降；需用 display:none 才能真正塌掉布局盒。

3. CSS 硬地板
Desktopmodules/css/widgets.css 中 .desktop-widget 定义 min-width:120px; min-height:60px; contain: layout style。小于 120px 的目标尺寸必须先 inline 覆盖 min-width/min-height。

推荐实现（挂件脚本内）：
var root = myRootDiv.getRootNode();          // ShadowRoot
var wrapper = root.host;                      // contentWrapper（attachShadow 的宿主）
var frame = wrapper.closest('.desktop-widget');
frame.style.minWidth = '0px';
frame.style.minHeight = '0px';
frame.style.transition = 'width .44s ease, height .44s ease';
var id = frame.dataset.widgetId;
var wd = window.VCPDesktop.state.widgets.get(id);
if (wd) wd.fixedSize = true;                  // 断开自动测量，防止与手动尺寸互斗
function setSize(w, h){
  frame.style.width = w + 'px';
  frame.style.height = h + 'px';
  wrapper.style.width = '100%';
  wrapper.style.height = '100%';
}

配套要点：
- 折叠时隐藏子区域用 display:none，不要用 opacity:0。
- 外框与内层应共用同一条 transition 曲线与时长，否则出现边框先动内容后动的错位。
- 拖拽抓手带 .desktop-widget-grip 绑在外框上（position:absolute; top:0; left:0; right:0; height:6px），外框缩小后抓手带自动跟随，无需额外处理。
- 若挂件本身需要自动适配内容（如聊天流增长），则不应设 fixedSize；自定义尺寸与自动尺寸二者互斥，需按挂件形态取舍。

关联节点：VCPdesktop 挂件沙箱与 Shadow DOM 代理、ALLOWED_KEYS 权限闸门、widgetManager 施工态与 MutationObserver。
