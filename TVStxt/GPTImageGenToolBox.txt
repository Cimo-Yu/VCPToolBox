# GPT Image 2 图像生成与编辑能力 (GPTImageGen)
本模块采用动态折叠收纳：平时仅显示本行摘要；当对话语义与某个子模块相关时，对应模块才会自动展开，无需主动索取完整文档。

[===vcp_fold:0.42::desc:用户想要生成一张图片、画一幅画、画个头像壁纸海报logo插画、文生图、根据文字描述创作图像、画图、出图===]

## 一、文生图 (GPTGenerateImage)
通过 OpenAI 兼容 API 调用 gpt-image-2 生成高质量图像。请在回复中使用以下精确格式发起调用（所有参数值用「始」「末」包裹）：
<<<[TOOL_REQUEST]>>>
tool_name:「始」GPTImageGen「末」,
command:「始」GPTGenerateImage「末」,
prompt:「始」(必需) 图像的详细描述。建议英文以获得最佳效果，中文亦可。画面风格、主体、动作、镜头语言、文字排版都直接写进 prompt。「末」,
size:「始」(可选) 宽x高，如 1024x1024 / 1536x1024(横) / 1024x1536(竖) / 2048x2048。默认 1024x1024。「末」,
quality:「始」(可选) low=快速低成本 / medium=均衡 / high=精细高成本 / auto。默认 auto。「末」,
n:「始」(可选) 生成数量 1-4，默认 1。「末」
<<<[END_TOOL_REQUEST]>>>
- 模型无负面提示词参数：不希望出现的内容写在 prompt 末尾，用 "Avoid: blurry, low quality, deformed hands" 模拟。
- 生成耗时 30-120 秒属正常，插件已内置 429/503 自动重试。
- 收到返回的图片 URL/路径后，用 <img> 标签直接展示给用户。

## 二、图生图 / 垫图 / 多图参考 (GPTEditImage)
以已有图片为基础进行编辑或生成新图，无需手动遮罩，通过文本指令引导修改：
<<<[TOOL_REQUEST]>>>
tool_name:「始」GPTImageGen「末」,
command:「始」GPTEditImage「末」,
prompt:「始」(必需) 描述希望如何修改或以参考图生成什么。建议英文。「末」,
image:「始」(必需) 原始图片：HTTP(S) URL、base64 data URI、或本地路径(如 image/gptimagegen/xxx.png)。多图参考用 JSON 数组 ["url1","url2"]，最多 16 张。「末」,
size:「始」(可选) 输出尺寸，默认 1024x1024。「末」,
quality:「始」(可选) low / medium / high / auto，默认 auto。「末」
<<<[END_TOOL_REQUEST]>>>
- 单张输入图片不超过 4MB，支持 PNG/JPEG/WebP/GIF。
- 典型用途：垫图重绘、风格迁移、局部修改、画质增强、角色一致性多图参考。

## 三、参数速查与最佳实践
- 尺寸表：1024x1024(方) / 1536x1024(横) / 1024x1536(竖) / 2048x2048(2K) / 3840x2160(4K横·最大档) / 2160x3840(4K竖·最大档) / 2880x2880(4K方·最大档)。
- 双重上限：最长边≤3840 且 总像素(宽x高)≤8,294,400（即 3840x2160 的面积预算）。3840x3840、4096x4096 等"长边达标但超面积"的组合会被拒绝。
- 质量档位：low 快速廉价适合草稿与配图；medium 日常均衡；high 精细高成本，留给最终成品。
- 大尺寸生成更慢，失败时先降尺寸或降质量重试。
- background 仅支持 opaque / auto（官方不支持 transparent，部分反代可能兼容）。
- 成本敏感时 quality 用 low、n 用 1，先验证构图再高质量重生成。
