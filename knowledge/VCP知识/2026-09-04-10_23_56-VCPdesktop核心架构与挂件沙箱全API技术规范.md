# VCPdesktop 核心架构与挂件沙箱全 API 技术规范

## 一、系统双层架构与物理边界

VCPdesktop 采用壁纸画布与挂件沙箱两层物理隔离设计：

1. **壁纸层 (Wallpaper Canvas)**
   - 运行载体：独立 `<iframe>`（加载本地 HTML/视频/图片文件）。
   - 环境限制：纯受限沙箱，**不注入** `vcpAPI`、`musicAPI`、`window.VCPDesktop`，不接收常规鼠标交互。
   - 生命周期：受 `visibilityFreezer.js` 管辖。窗口最小化或完全被遮挡时，将冻结所有 CSS 动画、Web Animations、Canvas 渲染与视频音频播放。
   - 跨层联动规范：若壁纸需响应系统硬件/天气/音乐指标，须通过常驻「隐形中继挂件」在挂件层拉取数据后，向壁纸 iframe 发起 `postMessage` 通信，由壁纸内部监听并修改 CSS 自定义属性。

2. **挂件层 (Widget Layer)**
   - 运行载体：主桌面 DOM 树中的独立容器，内容包裹在 `Shadow DOM (open)` 中。
   - 样式隔离：每个挂件独立 ShadowRoot，内联 `<style>` 自动提升至根部，不受宿主及其他挂件 CSS 干扰。
   - 自动尺寸：受 `MutationObserver` 监听驱动，默认在内容变动时防抖重算宽高。

## 二、挂件沙箱（Widget Sandbox）深度运行机制

每个挂件脚本通过 IIFE 包裹在沙箱中执行：`(function(_realDoc, _realWindow){ ... })(window.document, window)`

### 1. 宿主环境暴露与隐藏变量
- `widgetId` (string)：沙箱预注入的当前挂件唯一标识字符串。
- `window` (Proxy)：代理了宿主真实 `window` 对象。
  - 特殊拦截：`addEventListener`、`setInterval`、`setTimeout`、`requestAnimationFrame` 均被包装注入任务追踪器与生命周期钩子，挂件销毁时自动全量清理，杜绝内存泄漏。
  - 直接穿透：未被拦截的属性（如 `window.VCPDesktop`、`window.innerHeight`、`window.innerWidth`、`window.location` 等）全部无缝访问宿主上下文。
- `document` (Proxy-like Object)：
  - `querySelector` / `querySelectorAll` / `getElementById` 均严格限定在当前挂件的 Shadow DOM (`root`) 范围内。
  - `document.body` / `document.documentElement` 指向挂件的内容容器。
  - `createElement` 等构造函数透传至真实 document，确保 DOM 原型链一致。

### 2. 沙箱内内置原生 API
- **`vcpAPI` (后端通信与模型推理)**：
  - `vcpAPI.weather()`: 返回气象实时/逐小时/逐日/空气质量 JSON。
  - `vcpAPI.fetch(endpoint, opts)`: 访问 VCP 后端 `/admin_api/*` 端点（自动 Basic Auth 认证）。
  - `vcpAPI.post(messages, opts)`: 安全调用 OpenAI 兼容模型，无需前端暴露 API Key。
- **`musicAPI` (跨窗口媒体引擎)**：
  - `musicAPI.getState()`: 获取当前播放曲目、时长、进度、音量与播放状态。
  - `musicAPI.play()` / `musicAPI.pause()` / `musicAPI.seek(secs)` / `musicAPI.setVolume(0-100)`.
  - `musicAPI.send('music-remote-command', 'next' | 'previous')`: 跨进程切歌。
- **`widgetFS` (挂件私有持久化文件系统)**：
  - 触发前提：挂件须通过收藏系统持有 `savedId`（由 `VCPDesktop.favorites` 生成）。
  - `widgetFS.saveFile(fileName, content, encoding)`: 将数据持久化保存到挂件专属目录 `AppData/DesktopWidgets/{savedId}/`。
  - `widgetFS.loadFile(fileName)`: 读取挂件专属目录中的指定文件。
  - `widgetFS.listFiles()`: 列出专属目录下的自定义文件。
- **`window.VCPDesktop.dock.launch(item)`**：
  - 支持统一启动 VChat 内部 13 个子应用 (`type: 'vchat-app'`)、Windows 快捷方式 (`type: 'shortcut'`) 及内置挂件 (`type: 'builtin'`)。内置 2000ms 防抖防重。

### 3. 高级控制与排版黑魔法
- **掐断自动尺寸 (Fixed Size)**：
  在挂件脚本内执行：
  ```javascript
  var wd = window.VCPDesktop.state.widgets.get(widgetId);
  if (wd) {
      wd.fixedSize = true; // 拦截 autoResizeWidget 逻辑
  }
  ```
  可防止长条型 Dock、固定宽高复杂仪表盘被 MutationObserver 挤压或错位。
- **挂件自定位 (Auto-docking to Waterline / Relative Pos)**：
  利用 `widgetId` 获取宿主挂件的外层 DOM：
  ```javascript
  var wd = window.VCPDesktop.state.widgets.get(widgetId);
  if (wd && wd.element) {
      // 动态计算水线高度并吸附
      var waterY = window.innerHeight * 0.74;
      wd.element.style.top = waterY + 'px';
  }
  ```
- **锁定态兼容**：
  读取 `window.VCPDesktop.state.desktopLocked`。当桌面锁定激活时，挂件关闭按钮与抓手隐藏，层级点击提升自动被抑制。

## 三、脚本引用与外部加载规范
1. **内联脚本**：`<script>...</script>` 会由 `widgetManager.js` 直接注入沙箱包裹。
2. **本地外部脚本**：`<script src="app.js">` 或 `file://` 协议，系统会自动 fetch 源码并注入沙箱 IIFE 执行。
3. **跨域/第三方库**：CDN 脚本（如 Three.js / Chart.js 等）自动放行原样加载。
