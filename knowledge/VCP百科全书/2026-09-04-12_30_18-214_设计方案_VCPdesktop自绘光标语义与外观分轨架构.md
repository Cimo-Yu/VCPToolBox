# VCPdesktop 自绘光标：语义与外观分轨架构（设计方案）

## 核心概念
在 VCPdesktop 中用 DOM 元素替换系统鼠标光标是可行的，且不需要任何原生层改动。可行性来自一条事实：桌面窗是普通不透明窗（无 transparent、无 setIgnoreMouseEvents），故光标问题是纯客户区 DOM 问题。

架构核心是**把"外观抑制"与"意图申报"拆成两条独立通道**。

## 为什么直觉方案必死
直觉路线：全局 `cursor:none !important` 抑制系统光标，再用 `getComputedStyle(el).cursor` 读元素本来该显示什么形状，据此选择自绘图形。

该设计自我否定：`!important` 抑制后所有元素的 computed cursor 都是 `none`，判据被抑制动作本身擦除。

一般化：**凡"压制某属性后又以该属性为输入"的设计必死。** 解法是另开一条只承载语义的通道。

## 双通道设计

### 抑制通道（外观）
```css
html.vcp-cursor-on, html.vcp-cursor-on *,
html.vcp-cursor-on *::before, html.vcp-cursor-on *::after { cursor: none !important; }
/* 例外：app-region drag 区交还系统光标 */
html.vcp-cursor-on #desktop-title-bar,
html.vcp-cursor-on #desktop-title-bar * { cursor: default !important; }
```
每个 shadowRoot 内需另补 `* { cursor:none !important }`（继承不穿透，见 213 条目）。

### 语义通道（意图）
```css
html { --vcp-cursor: default; }
a[href], button, [role=button], label, summary,
.desktop-dock-icon, .desktop-shortcut-icon, .desktop-title-btn,
.desktop-widget-close-btn, .desktop-context-menu-item,
.desktop-sidebar-tab, .desktop-settings-toggle   { --vcp-cursor: pointer; }
input:not([type=range]):not([type=checkbox]):not([type=radio]),
textarea, [contenteditable=true]                  { --vcp-cursor: text; }
.desktop-widget-grip, .desktop-sidebar-card       { --vcp-cursor: grab; }
body.vcp-cursor-dragging                          { --vcp-cursor: grabbing; }
```
自定义属性无 UA 样式表干扰，故跨 shadow 边界从宿主继承有效（机制见 213 条目）。

探针必须用 `e.composedPath()[0]`：
```js
const el = e.composedPath ? e.composedPath()[0] : e.target;
const want = getComputedStyle(el).getPropertyValue('--vcp-cursor').trim() || 'default';
```

## 合成层
```css
#vcp-cursor-layer {
    position: fixed; inset: 0;
    z-index: 2147483647;      /* 实测全站最高为 10002，取任意更大值即可 */
    pointer-events: none;      /* 必须，否则自身吃掉命中测试 */
    display: none;
}
html.vcp-cursor-on #vcp-cursor-layer { display: block; }
html.vcp-cursor-on.vcp-cursor-blind #vcp-cursor-layer { visibility: hidden; }
.vcp-cursor-node { position:absolute; top:0; left:0; will-change: transform; }
```
**不要加 `contain`**：会使该元素成为 containing block，与内部 `position:fixed` 子元素语义冲突。

层须 appendChild 到 `document.body`，不可放入 `#desktop-canvas`（z-index:1 且 `overflow:hidden`，会截断）。

## 运动实现：箭头直写 + 环自终止
```js
function onMove(e) {
    if (e.clientX === undefined) return;
    x = e.clientX; y = e.clientY;
    document.documentElement.classList.remove('vcp-cursor-blind');
    /* 语义探针见上 */
    arrow.style.transform = `translate3d(${x}px,${y}px,0)`;  // 零延迟
    if (!raf) raf = requestAnimationFrame(tick);
}
function tick() {                                  // 仅跟随环需插值
    raf = 0;
    rx += (x - rx) * 0.18; ry += (y - ry) * 0.18;
    ring.style.transform = `translate3d(${rx-17}px,${ry-17}px,0)`;
    if (Math.abs(x-rx) > 0.3 || Math.abs(y-ry) > 0.3) raf = requestAnimationFrame(tick);
}
```
箭头在 handler 内直写 transform，因 Chromium 已把 mousemove 合并到帧节奏，无额外成本。跟随环的 rAF 自终止（位移 <0.3px 退出），故静止即零开销。

SVG path 起点取 `M0 0`，使热点自然落在 (0,0)，无需额外偏移量。

## 事件接线（三个黑洞的处置）
```js
document.addEventListener('mousemove', onMove, { passive:true });
document.addEventListener('dragover',  onMove, { passive:true }); // dnd 期间不发 mousemove
document.addEventListener('mouseenter', () => { pointerInside = true; });
document.addEventListener('mouseleave', () => { pointerInside = false; blind(); });
window.addEventListener('blur', () => { if (!pointerInside) blind(); });
document.getElementById('desktop-title-bar')
        ?.addEventListener('mousedown', blind);    // 拖窗即失明
```
**blur 必须带 `pointerInside` 条件**：置底模式每 1.5s 夺焦-交还（`desktopHandlers.js:2643`），无条件 blind 会导致光标周期性闪烁。

## 冻结协议自动满足
`body.desktop-frozen *` 规则只停 `animation-play-state` 与 `transition`，不影响 transform 直写。且窗口被遮挡时收不到 mousemove → rAF 自然停摆。故无需为 visibilityFreezer 做任何适配。

一般化：**把运动绑定到输入事件而非时间，冻结语义免费得到。**

## 零残留退场
现有数十处 `cursor:pointer` 声明**一行不删**：被 `!important` 压住，同时作为可读文档留在原处。摘掉 `html.vcp-cursor-on` 整套系统即刻退场，无残留。

## 已知漏点（不可解或可接受）
1. 挂件内嵌 iframe 跨文档无法注入，该区域光标失控。
2. 原生表面（select 弹层、文件对话框）恒显系统光标。
3. 标题栏 32px 内退回系统箭头（app-region drag 是否投递 mousemove 未实测，故以 CSS 例外兜底）。

## 待定的产品判断
影内是否强抑制。挂件为 AI 推送的第三方内容：强抑制＝替作者决定光标外观；放任＝指针进挂件时闪回系统箭头。倾向强抑制（"一个桌面只该有一个光标"优先于挂件自治），但属产品判断而非技术判断。
