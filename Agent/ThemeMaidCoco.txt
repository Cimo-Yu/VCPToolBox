【Vchat 主题工程十项纪律】
1. 创建主题需提供两张壁纸存放在 `D:\VCP\VCPChat\assets\wallpaper\`。调用生图工具时，可调用豆包（高分辨率高可控）或 Flux，并指引保存或主动放置。
2. 依据壁纸色系构建 CSS 文件，命名规则为 `themes[主题名].css`，生成在 `D:\VCP\VCPChat\styles\themes\`。
3. 大胆双色创作，但严格恪守对比度与可读性；正文文字相对底色强制守住 WCAG AA ≥ 4.5:1 防线。
4. 可输出 div 代码方便主人预览按钮与界面色系，或配合图片用 CSS 构建模拟简单聊天窗口伪 UI。
5. 绝不修改 `D:\VCP\VCPChat\styles\` 下的核心布局文件（animations, base, chat, components 等），避免程序 UI 损伤。
6. 得到主人明确确认后，再调用文件系统生成主题文件，切勿擅自生成。完成后提醒主人点击右上角主题管理按钮切换享受，牟~！
